# 01 · 设计理念（Design Philosophy）

> 版本 v0.1 · 2026-09
> 本文档回答一个问题：**SPIKE ELITE 到底要成为什么样的游戏，以及我们刻意不做什么。**

---

## 1. 北极星（North Star）

> **让一个从未摸过排球的人，三分钟内打出一记"哇哦"的扣球；让一个排球迷，在手机上还原出他在电视上看到的那记后排攻。**

所有设计决策都用这把尺子量：
- 它是否降低了排球这项运动的上手门槛？
- 它是否在高手手里仍有深度和天花板？
- 它是否让玩家感觉自己是在打排球，而不是在玩一个"排球皮"的反应游戏？

## 2. 三条产品信念

### 信念一：排球天然适合手游，只是没人做对
排球是**回合制 + 高爆发**的运动：一个回合 3–10 秒，节奏快、操作窗口短、单次触球只持续几百毫秒。这天然适配手机"碎片时间"场景——一次发球、一个回合、一局三局两胜 5–8 分钟，正好是通勤长度。

FC Mobile / 2K Mobile 之所以成功，不是因为足球/篮球"适合手机"，而是因为它们把一项连续运动切成了可掌控的片段。排球本身就是片段化的，我们不需要切它，只需要**忠实呈现它的节奏**。

### 信念二：真实感是护城河，不是装饰
体育游戏的复玩率来自"我上局那个球真的是我打出来的"的认同感。这意味着：
- 球的物理（飘球、旋转、扣球角度、触网）要像真的；
- 球员动画要能看出"这个人跳得高 / 臂展长 / 反应快"；
- 失误要让玩家觉得"是我时机没抓好"，而不是"游戏坑我"。

我们**不**做《马里奥网球》那种夸张化物理。我们做的是"穿运动服的 Forza"——入门宽容，专业玩家能区分出手感差异。

### 信念三：品类空白 = 机会窗口，但也是责任
因为没有竞品，我们的设计既没有可抄的范式，也没有可参考的失败案例。这要求我们：
- **早期就把规则正确性焊死**：FIVB 规则错一点，硬核玩家立刻流失；
- **尽早拉真实排球运动员/教练试玩**：他们能一眼看出"这个扣球动作不对"；
- **不要因为没人做过就自己发明规则**：先做忠实模拟，再做玩法创新。

## 3. 我们刻意不做什么（Non-Goals）

| 不做 | 原因 |
|---|---|
| 沙滩排球 / 排球少年风动漫题材 | 这是另一个产品（且已有《Harold's Xtreme Volleyball》等）。首发聚焦**室内 6v6**，建立写实模拟口碑。 |
| 全自动"看比赛"模式 | 2K Mobile 的 Coach 模式是给碎片时间设计的。我们保留**半自动**（AI 跑位，玩家触球瞬间接管），但不做纯挂机。 |
| Pay-to-win 数值碾压 | 卡牌可以影响属性，但**技术操作（时机、方向、位置）必须永远是决胜因素**。对标 FC Mobile 的 PlayStyles 思路：卡牌给风格，不给无敌。 |
| 开放世界 / 生涯 RPG | 首发做竞技 + 球队养成，不做长篇剧情线。那是主机预算。 |

> **平台策略（2026-09-27 修订）**：首发做 **PC（Steam）版**，用键鼠/手柄，全力推画面与操作手感；验证玩法后再移植手游。详见 [04-tech-stack.md](04-tech-stack.md)。
> **视角策略（2026-09-27 修订）**：第一人称视角是**核心卖点之一**，和第三人称/俯视并存。详见 GDD §2。

## 4. 目标玩家画像

### 核心玩家（20% 用户，80% 收入与社区声量）
- 18–35 岁，看 FIVB Nations League / 奥运 / 日本 V.League / 意超；
- 在现实中打俱乐部或高校排球，知道"二次球"和"后排攻"区别；
- 玩过 FC Mobile / 2K Mobile / eFootball，对卡牌游戏有耐受度。

### 主流玩家（60% 用户）
- 16–28 岁，喜欢竞技手游，不一定打排球；
- 被"操作爽、回合短、可以和朋友联机"吸引；
- 对规则一知半解，需要渐进式教学。

### 休闲玩家（20% 用户）
- 随便打打、看动画/短视频入坑、收集好看球员卡；
- 不碰排位，打打活动和 AI。

## 5. 体验支柱（Pillars）

1. **一触球就爽**（Juicy touch）：每次发球/垫球/扣球都有即时、可感知的反馈——震屏、音效、慢动作回放、观众反应。
2. **回合像真正的排球**（Real rally）：从接发 → 二传 → 进攻 → 拦防 → 防守反击，整条链条上玩家都有决策点，而不是只按一个键。
3. **我的球队我做主**（My squad）：收集、养成、化学、战术板——让玩家在开赛之前就已经投入情感。
4. **和朋友一起打**（Play together）：3v3 组队、友谊赛、俱乐部（League/Club）系统是留存核心。PvP 匹配是终点，但不是唯一路径。

## 6. 成功度量

首发后 6 个月内，我们认为成功的标志：
- D30 留存 ≥ 12%（体育手游品类基准 8–15%）；
- PvP 对局平均时长 ≥ 4 分钟；
- 应用商店评论关键词中"真实"、"手感"、"终于有排球了"出现频次 > "氪金"、"难"、"假"；
- 至少一支半职业/职业排球队或运动员在社媒自发提到本作。
