# 验收修复：球轨迹不清、看不清场上发生了什么（2026-11-28）

用户反馈："球的轨迹也不明确，无法观看到在场上发生了什么，需要增加击球特效和动画。"

## 修复内容（全部只影响视觉，不碰规则）

`AVolleyballBall` 现在每帧维护三组表现元素：

1. **飞行轨迹**：14 个拖尾点，每 28 ms 采样一次球心位置，由头部的暖黄渐变到尾部的冷蓝，
   尺寸从 0.16 递减到 0.035，落地后逐点消散而不是瞬间消失。
2. **预测落点环**：按抛体解析解求落地时刻（忽略空气阻力），在地面画一个脉动圆环，
   只在球真正飞行（速度 >120 cm/s 且高度 >14 cm）时显示。
3. **击球闪光**：`PlayHitBurst(Power)` 在接触瞬间生成一次 0.28 s 的闪光；
   强度由力量映射（600→2800 cm/s 归一化），轻触是小而偏冷的白蓝，
   重扣是大而炽热的橙红。

调用点：`SpikeEliteGameMode` 的两处实际触球提交处（战术触球与常规触球）。
