# 06 · 美术方向（Art Direction）

> 版本 v0.1 · 2026-09
> 一句话：**"电视转播里的排球比赛"，不是动漫，不是写实到恐怖的恐怖谷。**

---

## 1. 整体风格

- **风格化写实**（Stylized Realism）：球员比例接近真人，但面部略美化、肌肉线条略夸张——介于 NBA 2K 和《荒野大镖客 2》之间。
- **拒绝两种极端**：
  - 不要《排球少年！！》那种赛璐璐动漫风（那是另一个 IP 的地盘）；
  - 不要《Spike Volleyball》那种"看起来像 2012 年 PS3 游戏"的廉价写实。
- 参考：NBA 2K Mobile 角色质感、FC Mobile 球员特写、《网球世界巡回赛 2》的球场氛围。

## 2. 角色管线

- 扫描 / 高模雕刻 → Nanite 直接上桌（UE5 流程）；
- 面部：男女通用基础脸 × 8，再叠加发型、肤色、体型、纹身、护具组合；
- 体型分档：
  - MB（副攻）：195–210cm，肩宽、纵跳强；
  - OH（主攻）：190–205cm，均衡；
  - S（二传）：185–200cm，灵活；
  - L（自由人）：170–180cm，矮小快反应；
  - 女队对应比例缩放 92%；
- 球衣：真实联赛款（授权后）/ 原创款。球衣褶皱用 UE5 Cloth。
- 动捕：首发每位置 30–50 个核心动作，详见 M1 任务。

## 3. 场馆

- 首发 3 个场馆：
  1. **现代奥运馆**（12,000 座，蓝色座椅，标准 FIVB 照明）——默认；
  2. **欧洲 historic 体育馆**（木质地板，暖色灯光）——赛季解锁；
  3. **沙滩? 不，室内训练馆**（小、亲、暖色）——新手教程。
- 观众：用**Instanced Foliage / Niagara 公告板**做，不做逐人高模。High 档给观众席加粒子旗浪；Low 档直接用静态贴图。
- 场地：Volleyball court 18m × 9m，所有标线必须精确到厘米（FIVB 标准），因为玩家会盯着"这个球有没有出界"。

## 4. UI / 视觉语言

- 主色：**电光蓝 + 荧光黄**（排球官方用色联想）+ 深炭灰背景；
- 字体：标题用粗体无衬线（Roboto Condensed / 思源黑体 Bold）；
- 卡牌：竖版球员卡，位置缩写在左上角，PlayStyle 图标在底部；
- 比赛 HUD：极简——比分在顶部中央，当前回合球位置用一条**轨迹预测虚线**（可关）；
- 强调"慢动作时刻"：得分瞬间自动进入 3 秒回放，镜头机位参考真实排球转播。

## 5. 特效

- 扣球：空气扭曲 + 击球点小火花（不夸张）；
- 拦网成功：蓝色冲击环；
- 救球：尘土/汗珠粒子；
- 跳发过网：球拖尾（可关，不破坏真实感）；
- **不**做：彩虹、爆炸、奥特曼光线——我们是体育游戏，不是乱斗游戏。

## 6. 音频方向

- 解说：模仿真实转播——两人搭档，一人主说一人调侃；
- 现场声：观众声随比分紧张度动态变化；
- 击球声必须物理化：前臂垫球（闷）、手掌传球（脆）、扣球（爆）、触网（嗖）；
- BGM：主菜单用低频电子+鼓点，比赛中几乎不放音乐（让现场声成为主角）。
