# 03 · 游戏设计文档（Game Design Document v0.1）

> 本文档是活的。每个分支改动玩法时，先改这里。

---

## 1. 规则基础

严格遵循 **FIVB 2025–2028 官方规则**：

- 6v6，每局 25 分（决胜局 15 分），三局两胜（短局模式可选一局制）。
- Rally point scoring：每回合都得分。
- 一方赢得对方发球权后，全员**顺时针轮换一位**（位置 1→2→3→4→5→6→1）。
- 三次触球内必须过网，同队不得连续两次触球（拦网触球不计入三次）。
- 位置：1 号位（发球/后排右）、2 号位（前排右）、3 号位（前排中）、4 号位（前排左）、5 号位（后排左）、6 号位（后排中）。
- **Libero（自由人）**：只能在后排换人上场，不得发球/扣球/拦网，穿不同颜色球衣。
- 进攻体系：5-1（单二传）、6-2（双二传，后排二传组织）、4-2。首发默认 5-1，可选 6-2。
- 触网、位置错误、四次击球、后排队员前排进攻违例——全部判定。

## 2. 视角与镜头

| 模式 | 镜头 | 用途 |
|---|---|---|
| **默认：高位肩后镜** | 略高于拦网手，跟随你控制的球员，能看到全场 | 手动比赛 |
| **战术俯视镜** | 45° 高位俯瞰半场 | 选阵容、叫战术、设置接发阵型 |
| **回放镜** | 多机位（侧拍/网前/观众席） | 得分后自动 3 秒慢放，可手动保存 |
| **直播镜** | 电视转播式固定机位 | 教练模式 / 观战 |

## 3. 操作体系

### 3.1 默认半自动（推荐）
- AI 自动跑位、接发阵型、防守落位；
- 玩家只在**球即将到达自己控制的球员**时，屏幕中央出现操作提示条：
  - **垫球/传球**：左右滑动选择目标（二传 / 网前对方空当），松开时机决定精度；
  - **扣球**：按住蓄力，滑动方向选择线路（斜线/直线/长线/短线），在最高点松开；
  - **吊球**：轻扫一下；
  - **拦网**：球在对方扣球时，滑动方向选择并起跳时机；
  - **发球**：划弧线决定发球类型（跳发/飘球/下手球）和落点。
- 每次触球的"决策窗口"约 0.4–0.8 秒，对应真实排球反应时间。

### 3.2 全手动模式
- 左侧虚拟摇杆移动，右侧按键组：跳跃 / 触球动作 / 换人。
- 适合高手和蓝牙手柄玩家。

### 3.3 教练模式（Run The Court）
- AI 全自动打完整回合，玩家只在每局叫暂停、换 Libero、调整战术，以及**关键分（20 平以后）**接管最后一攻。

## 4. 球员与位置

| 位置 | 缩写 | 核心属性 |
|---|---|---|
| 主攻 Outside Hitter | OH | 扣球力量、挥速、接发稳定性、弹跳 |
| 副攻 Middle Blocker | MB | 拦网高度、拦网时机、快攻速度、弹跳 |
| 二传 Setter | S | 传球精度、战术组织、二次球、视野 |
| 接应 Opposite | OPP | 强攻、后排攻、发球 |
| 自由人 Libero | L | 防守面积、一传精度、反应、救球 |

球员卡稀有度：Common → Rare → Epic → Legendary → **Icon（名宿）**。
每张卡有 3 个 PlayStyle（见市场调研表 A.1），PlayStyle 在回合中触发时有特写镜头。

## 5. 游戏模式

```
主线模式
├── 快速比赛（Quick Match vs AI，3 难度）
├── 排位赛（Ranked，1v1 或 3v3 组队，赛季制）
├── 锦标赛（Tournament，淘汰赛结构，周/月常设）
├── 名场面（Rewind，还原经典比赛回合）
└── 生涯/球队模式
    ├── 我的球队（My Team）：抽卡、养成、化学、球衣定制
    ├── 赛季模式（Season）：打一整个联赛/国家联赛赛程
    └── 俱乐部（Club/公会）：和同公会成员打俱乐部对抗赛
```

首发不含剧情 RPG。

## 6. 经济与 live-service

- **货币**：金币（免费）、钻石（付费）、球员合约（抽卡券）。
- **Battle Pass（赛季通行证）**：每赛季 60 级，免费/付费双线，奖励球员卡、球衣、特效。
- **卡包**：基础包（金币可买）、精英包（钻石）、赛季限定包。
- **每日/每周任务**：打 3 场、完成 5 次完美垫球、赢一场排位——给金币和合约。
- **限时活动**：跟随真实世界排球赛事（奥运会、国家联赛、世锦赛）出对应主题卡。
- **反 Pay-to-win**：属性差异封顶。两张同位置卡，Legendary 比 Common 强约 15–20%，**但操作时机精度（玩家水平）影响占比 ≥ 60%**。

## 7. AI 设计

- **队友 AI**：接发阵型自动落位、二传自动选择最佳攻手、防守时按战术板补位。
- **对手 AI 难度分层**：
  - Easy：只打基础线路，接发失误多；
  - Normal：会用 2–3 种战术，偶有吊球；
  - Hard：会针对你的拦网位置调线路、跳发追人、后排攻；
  - Legend：会算轮换、在关键点发短球破坏你的接发。
- AI 不能"完美预判"——它必须也有反应时间窗口，否则玩家会觉得不公平。

## 8. 网络与 PvP

- 实时 6v6 不现实（移动端网络+同步成本太高）。**首发 PvP 是 1v1（你控制一队 6 人，AI 辅助）**。
- 后续加 3v3 组队（每人控制 2 个位置 + AI）。
- 回合同步采用**锁步+输入延迟**模型（参考 Rocket League Sideswipe），每回合 3–10 秒，对网络波动容忍度高。
- 支持 WiFi/5G，3G/4G 下走异步对战（照录像回放，参考 FC Mobile 的 Head-to-Head 某些模式）。

## 9. 教学与新手引导

- 前 10 分钟：在半场内教发球 → 垫球 → 二传 → 扣球，四步解锁；
- 第一次被拦网后，弹出"如何选择扣球线路"；
- 第一次打满一局后，解锁"轮换规则"可视化教学；
- **不**做长动画教学。每个操作即时提示，打完就忘。

## 10. 音频

- 中文/英文/日文/西语/葡语/意大利语解说（首发中英，后续扩展）；
- 击球音效必须**物理化**：不同部位触球（拳/掌/前臂）声音不同；
- 场馆观众声随比分紧张程度变化（24 平后自动安静 → 得分爆发）；
- 授权 BGM 谨慎使用——首发用原创电子/运动风格配乐，避免版权成本。
