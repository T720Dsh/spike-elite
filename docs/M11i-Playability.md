# M11i：试玩反馈修复（2026-10-03–04）

范围：发球预览与拖拽、Alt 鼠标操作、文字越界、接球/二传/扣球动作。基线 `6b2eead`；不增加新模式、不修改计分与换人规则、不引入外部美术资产。

## 改动与操作

- 正常比赛与发球训练共用白色三维虚线、立体箭头和落点标记。点击对方场地选落点，按住左键上下拖动调整弧度；拖动不会使已选落点漂移。发球前采用斜上方机位，完整展示弧线，出球后恢复原视角。
- 预览和真人发球共用 `BuildShotSolution`，在开始抛球时锁定出球速度；AI 保留原有误差和教练偏好。鸣哨前不能发球，8 秒时限没有被界面暂停或跳过。
- 修复控制器默认隐藏导致其所属轨迹网格不渲染的问题；共享材质修复了以前只有最后一个点更新风险颜色的问题。组件池复用，无逐帧生成 Actor。
- Alt 显示/收起实时鼠标面板；可点击发球、接一传、二传、扣球、抬手/拦网、跳跃、切换球员、教练和暂停。面板本身不暂停比赛；所有击球/发球仍经过 GameMode 的合法性与距离校验。暂停和收起按钮固定在面板底部。
- 拖拽区域消费左键事件并在松手/失去捕获时结束；鼠标显示期间停止摄像机转向，防止拖拽同时扭转视角。战术界面获得独占输入，取消后恢复 Alt 面板意图；菜单/暂停/比赛结束不会残留瞄准层或临时机位。
- 赛后技术统计使用限定宽度、分行排版和纵向滚动；三个操作按钮固定在安全区底部。暂停操作说明可换行、可滚动；底部 HUD 和发球提示设置宽度上限。布局随窗口与 UI 缩放重新计算。
- 接球、二传、扣球和发球使用连续的准备 → 触球 → 随挥 → 恢复曲线；球已击出时从触球段开始，不再倒放蓄力。触球前根据来球距离/抛球阶段准备，接球屈膝抬台、二传屈膝托举伸展、扣球挥臂随动。动作只影响视觉，不改变球的触球点、判罚或物理。扑救成功仍保持倒地恢复。

## 验收口径

`PlayabilityTest` 使用生产界面和处理函数，但由合成指针事件、按钮委托及开发状态夹具驱动，不是真人完整对局。它检查桌面/DPI 坐标往返、实际世界落点、鼠标捕获释放、拖弧保持落点、实际渲染的轨迹点、发球一次统计、Alt/暂停/战术输入恢复，并生成密集 24 人统计和末尾滚动截图。动作截图分为触球与随挥；截图夹具中的动作通知不是一次真实击球成功证据，真实击球路径另外由 Tactical/QuickMatch 验证。

纯逻辑新增 `ContactAnimationContinuity`、`MouseServeArcSolver` 两项（共 83 项）。前者检查连续曲线、触球起点与恢复终点；后者检查双方镜像的过网、弧高变化及落点误差。

截图不是只检查“有文件”：逐张查看白色虚线/箭头、自动发球机位、菜单说明、技术统计顶部/末尾和触球/随挥。渲染计数检查也不能代替截图验收。

## 边界

- 仍为程序化关节角色，不是骨骼动捕动画；没有新增手指抓球、全身 IK、真实手掌触球约束或专业动作资产。流畅度体验仍需真人试玩确认。
- 鼠标选点只接受对方场内，弧高有上下限；不是任意世界位置发球编辑器。球路预测保留真实重力/球半径/球网判定，未承诺所有弧度都能过网。
- 统计内容多时需要滚动；目标是文字始终可访问、按钮始终可见，不是把双方 24 人全部挤在一屏。
- 独立包和截图位于本机 ignored 目录，不上传 GitHub Release；不修改用户的系统缓存或驱动。构建限制为 4 个并行动作，缓解本机低可用内存/磁盘空间压力。
