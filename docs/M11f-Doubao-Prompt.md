## 1. M11f-1：先修战术状态与真实输入（最高优先级）

### 1.1 防守慢动作退出必须恢复

检查 `Private/UI/TacticalContactComponent.cpp`：

- `EnterDefensePlanning` 保存原TimeDilation后设0.3，却没有置`bWorldFrozen`。
- `RestoreWorldState` 只在`bWorldFrozen`或当前dilation≤0.2时恢复。
- 因此确认、取消、超时等防守退出路径可能一直停在0.3；面板关闭不代表世界状态恢复。

用显式的「本组件是否拥有时间缩放覆盖」状态，或统一的进入/退出函数修复。保存和恢复必须成对，不能靠当前浮点值猜战术状态；避免重复进入覆盖原保存值。不要粗暴每帧强制TimeDilation=1，因为会覆盖合法的外部时间缩放。

逐条验证：Enter→鼠标确认、Enter键确认、右键取消、Esc取消、超时AI默认、暂停、回合结束、MatchOver、Rematch、组件退出。每条检查TimeDilation恢复到进入前值、玩家输入/光标/输入模式符合当前菜单状态，旧面板事件不影响新回合。至少覆盖原dilation=1与非1的对照。新增生产组件/世界级回归，不只是独立计算一个bool。

### 1.2 防守触发半场语义统一

当前`bBallOnTheirSide`使用A时X<0、B时X>0，但GameMode A队TeamSide=+1/B=-1，发球点A=+1200/B=-1200。这与实际阵营半场相反。核对GameMode轮转/控球/球位置定义，建立单一球队局部坐标辅助函数，不再散落硬编码符号。

正常生产流程下测试A受控时B二传后即将进攻、镜像B受控时A进攻；未过网和已过网分别验证。正常发球不能误弹防守面板，对方已结束进攻不能反复重入同一次决策。测试日志必须包含回合ID、PossessingTeam、受控TeamSide、球X/速度/触球数、进入原因，不用`DevForceDefensePlanning`冒充自然触发。

### 1.3 面板防穿透与滚轮隔离

`TacticalHUDWidget::IsPointerOverPanel`将`GetMousePosition`的viewport坐标直接传给`CachedGeometry.IsUnderLocation`的absolute坐标，两种坐标不可直接混用。

统一到Slate绝对坐标，或将指针通过viewport geometry明确转换；不得仅乘一个固定DPI系数。窗口化、窗口挪动、不同系统DPI/游戏UI缩放都应正确。优先采用可靠的Slate命中/UMG事件路由，让UI输入消费有明确所有者。

当前TickPlanning仍无条件用MouseWheelAxis改变Power。必须实现：指针在二传列表/滚动条/卡片上，滚轮只滚动列表；指针在世界瞄准区，滚轮才改变力度。卡片点击仅选中，不确认；按下/释放、拖动滚动条、拖离按钮、双击均不能穿透到世界确认或击球。

检查Enter/Space激活焦点按钮与控制器直接读键是否同帧冲突。增加明确可见的「准备击球/确认」和「取消」动作及准确提示，确保鼠标、键盘、滚动条的输入语义一致。

### 1.4 自由轨迹真正可调，选择与执行一致

当前自由轨迹id14仍符合`bSetTactics`，Q/E继续切换列表，不能按注释所述手动调弧线。拆分「选择战术」和「自由调弧线」按键/状态：例如方向键始终切换卡片，自由轨迹下Q/E调弧线；同步修改提示。自由模式不应继承上一项锁定的Apex/目标造成名实不符。

进入二传面板就应用当前默认战术到Intent，不能高亮第一项而预览仍是通用默认。鼠标选择、键盘选择、Intent、预览、ActiveSetPlay以及执行的索引/id必须一致，分清0-based index与PlayId。为回调增加有效阶段/触球类型/当前回合校验，退出后旧卡片不能改Intent或防守计划。

检查BuildShotSolution与FShotIntent.ApexHeight的数据契约：战术表上的弧高不能只出现在文字里而被求解器忽略。明确由目标/时间确定弧线，还是按弧高求解，并让预览与执行使用同一解算。向下击球的最高点至少从起点初始化，`ApexAboveContact`不能因为Apex默认0变为不合理负数。

风险文案应使用实际轨迹结果的`bNetTouch / bInBounds / bCrossedNet / bValid`，区分触网、出界、无法求解、合法同侧传球与合法过网。现在同侧传球只判断界内、忽略触网，文字与预览颜色有不一致风险。不能用「未过网」统一惩罚所有二传/接球。

### 1.5 实际操作验收

在同一个可运行构建逐项操作14个二传和8个防守选项，覆盖鼠标、键盘、列表末项、自由轨迹、背飞、确认与取消。记录「输入源→选中index/id→Intent→确认→执行」；不能直接调用HandleSetPlayPicked就宣称鼠标验收通过。
