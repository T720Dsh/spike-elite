## M0 · 设计与原型（已完成的里程碑：M0–M4 开发里程碑）

**目标**：在 UE5 里证明"球的手感是对的"。

- [x] 市场调研、GDD v0.1、技术选型
- [x] UE5.8 工程初始化（纯 C++/UMG，无蓝图）
- [x] 一个体育馆壳子（白盒 → 完整室内馆）、网（权威碰撞）、地面标线
- [x] 自定义球弹道：发球、垫球（接发）、二传、扣球的物理曲线
  （拦网触球物理：未实现，列入 M11）
- [x] 1 个能跑的球员胶囊人（方块人），能跳、能挥臂、能击球
- [ ] 输入原型：屏幕滑动 = 扣球方向（当前为 PC 键鼠/手柄，移动端输入未做）
- [x] 里程碑产出：**PC 上能打出完整回合**（-QuickMatch 完整打完一局）
- [ ] 找 3–5 个真实排球玩家试玩，收集"手感对不对"的反馈

**退出标准**：测试者能用"爽"或"不爽"评价，而不是"看不懂怎么玩"。

## M1 · 垂直切片（已完成的里程碑：M5–M10 开发里程碑）

**目标**：做出一场完整、可玩、看着像样的 6v6。

- [x] 完整回合状态机：PreMatch → 发球(AwaitingServe/ServingToss) → Rally（接发 → 二传 → 进攻 → 得分/失误）→ BetweenRallies → SetOver → MatchOver → 轮换
- [x] 简化三次触球规则：控球队伍、0–3 触球、连击判罚、过网换边、界内/界外/压线判分、五局三胜 25/15 领先两分
- [x] 5 个 AI 队友 + 6 个 AI 对手：基础队伍协作（预测落点接发、指定二传、预选进攻、职责站位）
- [x] 1 个完整室内场馆（白天版本；夜晚光照版本未完成）
- [ ] 球员动捕首批动作集：发球/垫球/传球/扣球/拦网/救球（当前为方块人，无动捕动画；Mannequin 骨骼升级因资产引用损坏未实施，列入 M11）
- [ ] 3 档画质设置跑通移动端 60fps（PC 画质预设已实现，移动端未做）
- [x] 基础 UI：主菜单、快速比赛（-QuickMatch）、暂停、计分板、比赛结束界面
- [ ] 男女各 1 支国家队白模队
- [x] 里程碑产出：**PC 上打完一场完整比赛（一局制 3 分快速模式与完整 5 局规则共用同一套规则代码），不崩**
- [x] 规则自动化测试：18 项纯逻辑用例（界内/压线/界外/四触/连击/过网重置/单次结算/24:24 领先两分/决胜局 15/轮转/MatchOver 封盘/发球失误分类/球权生命周期/阶段门矩阵/自动发球策略）
- [x] M11a 稳定收口：确认弹窗状态机（Esc 只关确认框、取消精确还原状态）、`-devauto` 与正常游戏隔离（真人按 E 才发球）、MatchOver 输入门（世界暂停）、正式逻辑复用被测试规则核心、HUD/AI 更新节流、Android File Server 与 EnhancedInput 残留清理、Win64 打包卫生
- [x] M11b 国际比赛场馆与裁判（60×44×15 m 壳体、四面 ISM 看台、裁判架/记录台/替补席、实时记分牌）、回合缓冲与鸣哨（8 s 发球时限）、轮转 HUD（P1–P6 权威轮转数据）、可见肢体程序动画（11 姿态）、战术慢动作 + 虚线球路预览、数据驱动二传战术（13 种 + 自由轨迹）、真实拦网（不计触球/连续触球/打手出界）、倒地救球（扑救/恢复门）、比赛用球（无品牌黄蓝占位 + 授权插槽）、观众密度三档、27 项自动化测试

  （预览=实际击球）、屏幕 UMG 攻击/二传/防守面板（13+1 战术 + 8 项防守决策）、球结构回归修复、55 项自动化测试、

## M2 · Alpha / 封测（9–15 个月）

**目标**：加上长线系统和 PvP。

- [ ] 球员卡系统：抽卡、升级、PlayStyle 触发特写
- [ ] My Team：阵容、化学、球衣
- [ ] 排位赛 + 异步对战（录像回放）
- [ ] 实时 PvP 1v1（WiFi 环境）
- [ ] 赛季通行证骨架
- [ ] 账号系统、云存档
- [ ] 基础反作弊
- [ ] 里程碑产出：**封闭 TestFlight 500 人，两周内 D1 留存 ≥ 35%**

**退出标准**：留存数据说明这不是"demo 级好玩"，而是"第二天还想打开"。

## M3 · Soft Launch（15–20 个月）

**目标**：真实市场检验，地区小范围上线。

- [ ] 上线地区：菲律宾、加拿大、印尼（测试市场 + 排球狂热区）
- [ ] 完整经济系统、首充、月卡
- [ ] 跟随真实赛事的第一个限时活动（绑定 2027 年 FIVB 赛事日历）
- [ ] 多语言：英、中、日、西、葡、印尼
- [ ] 客服、内容更新管线（每周小版本）
- [ ] 里程碑产出：**Soft Launch 8 周，D30 留存 ≥ 10%，付费率 ≥ 2%**

**退出标准**：经济不崩、服务器不崩、玩家开始自己产出内容（剪辑/攻略）。

## M4 · Global Launch（20–28 个月）

**目标**：全球发行，签授权。

- [ ] 至少 1 个官方联赛/国家队授权落地
- [ ] 全球 PvP 匹配分区域服
- [ ] 内容管线稳定：每 2 月一个赛季
- [ ] 电竞赛事 / 社区锦标赛起步
- [ ] 后续平台评估：PC / Switch / Console（**不在首发承诺内**）

## 关键风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 授权拿不到（FIVB/联赛谈判慢） | 中 | 高 | M3 前用原创球员+社区投票；不把授权当上线前提 |
| 移动端 60fps 优化做不出来 | 中 | 高 | M1 就锁中端机测试，不要等到 M3 |
| 排球规则太硬核，路人玩不懂 | 中 | 中 | 半自动模式 + 渐进教学；找排球迷和路人各测一半 |
| 大厂（EA/2K）提前做排球 | 低 | 极高 | 速度是最大武器。18 个月内软启动建社区。 |
| 动捕成本超预算 | 中 | 中 | 先做核心动作 30 个，其余用 Mixamo + 手工补 |
