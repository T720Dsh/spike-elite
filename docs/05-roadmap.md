# 05 · 路线图（Roadmap）

> 版本 v0.1 · 2026-09
> 时间是粗排，按"垂直切片是否好玩"为真正闸门，不按日历。

---

## 阶段总览

```
M0  设计与原型          0–3 个月
M1  垂直切片 (Vertical Slice)  3–9 个月
M2  Alpha / 封测          9–15 个月
M3  Soft Launch           15–20 个月
M4  Global Launch         20–28 个月
```

---

## M0 · 设计与原型（0–3 个月）

**目标**：在 UE5 里证明"球的手感是对的"。

- [x] 市场调研、GDD v0.1、技术选型
- [ ] UE5.5 工程初始化，从 Lyra fork
- [ ] 一个体育馆壳子（白盒）、网、地面标线
- [ ] 自定义球弹道：发球、垫球、扣球、拦网触球的物理曲线
- [ ] 1 个能跑的球员胶囊人，能跳、能挥臂
- [ ] 输入原型：屏幕滑动 = 扣球方向
- [ ] 里程碑产出：**PC 上 1v1 对墙/对一个虚拟拦网，能打出完整回合**
- [ ] 找 3–5 个真实排球玩家试玩，收集"手感对不对"的反馈

**退出标准**：测试者能用"爽"或"不爽"评价，而不是"看不懂怎么玩"。

## M1 · 垂直切片（3–9 个月）

**目标**：做出一场完整、可玩、看着像样的 6v6。

- [ ] 完整回合状态机：发球 → 接发 → 二传 → 进攻 → 拦防 → 得分/失误 → 轮换
- [ ] 5 个 AI 队友 + 6 个 AI 对手，会跑基础战术
- [ ] 1 个完整场馆（白天/夜晚两个光照版本）
- [ ] 球员动捕首批动作集：发球(3 种)、垫球(2 种)、传球(2 种)、扣球(4 种线路)、拦网(2 种)、救球(3 种)
- [ ] 3 档画质设置，中端 Android 跑通 60fps
- [ ] 基础 UI：主菜单、快速比赛、暂停、计分板
- [ ] 男女各 1 支国家队白模队
- [ ] 里程碑产出：**iPhone 15 + 一台中端 Android 上，打完一局完整三局两胜，不崩**

**退出标准**：不看文档的人能自己打完一局并想再来一局。

## M2 · Alpha / 封测（9–15 个月）

**目标**：加上长线系统和 PvP。

- [ ] 球员卡系统：抽卡、升级、PlayStyle 触发特写
- [ ] My Team：阵容、化学、球衣
- [ ] 排位赛 + 异步对战（录像回放）
- [ ] 实时 PvP 1v1（WiFi 环境）
- [ ] 赛季通行证骨架
- [ ] 账号系统、云存档
- [ ] 基础反作弊
- [ ] 里程碑产出：**封闭 TestFlight 500 人，两周内 D1 留存 ≥ 35%**

**退出标准**：留存数据说明这不是"demo 级好玩"，而是"第二天还想打开"。

## M3 · Soft Launch（15–20 个月）

**目标**：真实市场检验，地区小范围上线。

- [ ] 上线地区：菲律宾、加拿大、印尼（测试市场 + 排球狂热区）
- [ ] 完整经济系统、首充、月卡
- [ ] 跟随真实赛事的第一个限时活动（绑定 2027 年 FIVB 赛事日历）
- [ ] 多语言：英、中、日、西、葡、印尼
- [ ] 客服、内容更新管线（每周小版本）
- [ ] 里程碑产出：**Soft Launch 8 周，D30 留存 ≥ 10%，付费率 ≥ 2%**

**退出标准**：经济不崩、服务器不崩、玩家开始自己产出内容（剪辑/攻略）。

## M4 · Global Launch（20–28 个月）

**目标**：全球发行，签授权。

- [ ] 至少 1 个官方联赛/国家队授权落地
- [ ] 全球 PvP 匹配分区域服
- [ ] 内容管线稳定：每 2 月一个赛季
- [ ] 电竞赛事 / 社区锦标赛起步
- [ ] 后续平台评估：PC / Switch / Console（**不在首发承诺内**）

## 关键风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 授权拿不到（FIVB/联赛谈判慢） | 中 | 高 | M3 前用原创球员+社区投票；不把授权当上线前提 |
| 移动端 60fps 优化做不出来 | 中 | 高 | M1 就锁中端机测试，不要等到 M3 |
| 排球规则太硬核，路人玩不懂 | 中 | 中 | 半自动模式 + 渐进教学；找排球迷和路人各测一半 |
| 大厂（EA/2K）提前做排球 | 低 | 极高 | 速度是最大武器。18 个月内软启动建社区。 |
| 动捕成本超预算 | 中 | 中 | 先做核心动作 30 个，其余用 Mixamo + 手工补 |
